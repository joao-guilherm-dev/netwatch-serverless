# Contribuindo

1. Abra uma issue para discutir mudanças relevantes.
2. Crie uma branch para sua alteração.
3. Execute `npm install`, `npm run typecheck`, `npm run lint`, `npm test` e `npm run build`.
4. Não inclua credenciais, tokens, dados de clientes ou recursos reais de produção.
5. Envie um Pull Request com descrição, testes e mudanças de infraestrutura.
